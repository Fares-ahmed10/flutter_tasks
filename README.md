OSC Flutter 2027 – Task Submissions 🚀

Welcome to the OSC Flutter 2027 Task Submission Repository!

Follow these steps to submit your tasks successfully.

---

🛠 Prerequisites

Make sure you have:

- A GitHub account
- Git installed on your computer
- A code editor (VS Code, IntelliJ, etc.)

Check Git installation:

git --version

---

1. Fork the Repository

Since you don't have direct write access to the original repository, you'll submit your work using a Fork.

1. Open the "original repository" (https://github.com/Sara-Abdelmoniem/flutter_tasks).
2. Click Fork in the top-right corner.
3. Click Create fork.

Now you have your own copy of the repository on GitHub!

---

2. Clone Your Fork

Open your fork on GitHub, click the green Code button, copy the HTTPS URL, then run:

git clone YOUR_FORK_URL

Enter the repository folder:

cd flutter_tasks

---

3. Create Your Personal Folder

Navigate to the correct task folder.

For example:

cd dart_session_1_task

Create a folder using your full name:

mkdir "Your Full Name"

Your submission should look like this:

dart_session_1_task/
├── Ahmed Mohamed/
├── Sara Ali/
└── Your Full Name/

Important:

- Use your real full name.
- Don't modify other students' folders.
- Keep your submission inside the correct task folder.

---

4. Add Your Solution

Place all your solution files inside your personal folder.

Make sure to include all necessary files and don't upload unnecessary generated files or caches.

For Flutter projects, don't include:

- "build/"
- ".dart_tool/"
- Personal credentials or API keys.

---

5. Push Your Submission

Open your terminal at the repository root and run:

Check your changes:

git status

Stage your submission:

git add .

Commit your changes:

git commit -m "Add Your Full Name - Task 01"

Push to your fork:

git push origin main

---

6. Create a Pull Request

Now your submission is uploaded to your fork!

1. Open your fork on GitHub.
2. Click Contribute then Open pull request (or use the Pull Requests tab).
3. Make sure the base repository is "Sara-Abdelmoniem/flutter_tasks".
4. Make sure the base branch is "main" and the compare branch is your fork's "main".
5. Click Create pull request.

That's it! Your submission is now waiting for review by the OSC Flutter team.

---

⚠️ Important Notes

- Always submit through a Pull Request.
- Don't push directly to the original repository.
- Don't modify or delete other students' submissions.
- Make sure your files are uploaded to the correct task folder.
- If you face any issues, contact the OSC Flutter team.

---

🎯 Happy Coding!

Remember, the goal is not just to solve the tasks, but also to practice Git and GitHub along the way.
